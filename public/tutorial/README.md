# Animaciones para el Tutorial de Navegación

Coloca en esta carpeta tus animaciones dibujadas a mano para los gestos táctiles y de navegación.
El visor soporta formatos **WebP animado** (.webp), **APNG** (.apng) y **GIF** (.gif).

### Nombres de archivo recomendados:

1. **Gesto de deslizar (Swipe / Pan):**
   - `deslizar.webp` (o `deslizar.apng` / `swipe.webp`)
   - *Descripción*: Un dedo o cursor arrastrando horizontalmente para mover la galería.

2. **Gesto de la pincita (Pinch to zoom):**
   - `pincita.webp` (o `pincita.apng` / `pinch.webp`)
   - *Descripción*: Dos dedos juntándose y separándose para acercar/alejar en el espacio tridimensional.

3. **Gesto de tocar / pulsar (Tap to focus):**
   - `tocar.webp` (o `tocar.apng` / `tap.webp`)
   - *Descripción*: Un dedo pulsando una obra para abrir la ficha técnica y texto curatorial.

4. **Recomendaciones y Búsqueda (opcional):**
   - `recomendaciones.webp` (o `recomendaciones.apng`)

### Recomendaciones técnicas:
- **Resolución ideal**: 480x320 px o 600x400 px (relación aproximada 3:2 o 16:9).
- **Fondo**: Transparente (alfa) o color `#f3f4f8` / `#ffffff` para integrarse con la estética del sitio.
- **Formato recomendado**: **WebP animado** ofrece el mejor balance de bajo peso y transparencia limpia de 8-bit.
